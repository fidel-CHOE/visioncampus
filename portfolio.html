마케팅 Value Chain의 이해

마케팅 프로세스 전체를 흐름으로 이해한다
교육 시간
3–4시간강의+토론 / 조정 가능
학습 대상
마케팅 입문자 · 타 직군에서 마케팅으로 이동한 실무자 · 마케팅 전반을 체계화하고 싶은 담당자
학습 목적

마케팅의 전체 흐름(Value Chain)을 이해하고, 각 단계에서 자신의 역할과 인접 영역 협업 포인트를 파악해 업무 우선순위를 스스로 설정할 수 있다.

학습 목표
01Marketing과 Sales의 차이, Needs와 Wants의 구분을 설명할 수 있다
02마케팅 Value Chain 전 단계(상품기획→PMS→MD→GTM→MOT→CS)를 설명하고 핵심을 말할 수 있다
03Goal Setting → 환경분석 → STP → 전략수립 → Action Plan의 마케팅 프로세스를 적용할 수 있다
